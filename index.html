Postar 개인정보처리방침

시행일: 2026년 10월 6일 · 개발자: Polobin.code

1. 수집하는 정보

Postar는 개발자 서버를 운영하지 않으며, 사용자의 개인정보를 개발자에게 전송하거나 수집하지 않습니다.

앱이 기능을 위해 사용자의 기기 안에만 저장하는 정보는 다음과 같습니다.

  • 메일 계정 정보(이메일 주소, POP3/SMTP 서버 주소, 비밀번호) — 비밀번호는 Android Keystore로 암호화해 저장
  • 받은 메일, 보낸 메일, 첨부파일, 연락처, 그룹, 앱 설정
  • (선택) 사용자가 직접 입력한 Gemini API 키 — 암호화해 저장

2. 정보가 전송되는 곳

  • 사용자가 설정한 메일 서버: 메일을 받고 보내기 위해 계정 정보와 메일이 해당 서버와 주고받아집니다.
  • Google Gemini (선택 기능): 사용자가 AI 기능을 직접 실행할 때에만, 요청한 메일 내용이 사용자 본인의 API 키로 Google에 전송됩니다. Google의 개인정보처리방침이 적용됩니다.
  • Google Play: 라이선스 결제와 구매 확인은 Google Play 결제 시스템이 처리합니다. 결제 수단 정보는 앱이 받지 않습니다.

3. 보관 및 삭제

모든 데이터는 앱을 삭제하거나 앱 설정에서 계정을 지우면 기기에서 삭제됩니다. 사용자가 직접 만든 백업 파일(.postarbak)은 사용자가 정한 비밀번호로 암호화되며, 저장 위치는 사용자가 선택합니다.

4. 제3자 제공 · 광고 · 분석

Postar는 광고, 사용 통계 분석, 추적 도구를 사용하지 않으며 사용자 정보를 제3자에게 판매하거나 제공하지 않습니다.

5. 권한

  • 인터넷 · 네트워크 상태: 메일 송수신
  • 알림: 새 메일 알림
  • 파일 선택: 첨부파일 추가 및 저장(사용자가 고른 파일만)
